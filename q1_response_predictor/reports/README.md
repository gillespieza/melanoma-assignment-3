# Reports Directory & Documentation Architecture

This directory contains the documentation, analytical reports, and benchmarking results generated by the **Melanoma Immunotherapy Response Predictor** pipeline (`q1-response-predictor`), structured into clear **Pillar Subdirectories**.


## 4-Pillar Narrative Architecture

The reports are organized into a 4-pillar directory hierarchy that progresses from data acquisition and baseline characterisation to feature engineering, subtyping, and multimodal predictive modelling:

```
reports/
├── README.md (This sitemap and documentation guide)
├── executive_summary.md (Cross-pillar synthesis & key findings)
├── Pipeline.md (Master pipeline workflow & technical implementation)
│
├── pillar-1-cohorts-and-preprocessing/
│   ├── cohort_characteristics_clinical.md
│   ├── cohort_characteristics_genomic.md
│   └── batch_correction_report.md
│
├── pillar_2_clinical_subtyping/
│   ├── feature_selection_report.md
│   └── clinical_phenotyping_and_feature_selection.md
│
├── pillar_3_transcriptomic_signatures/
│   ├── curated_signatures_report.md
│   └── curated_signatures_supplementary.md
│
└── pillar_4_out_of_cohort_benchmarks/
    ├── model_evaluation_report.md
    └── transcriptomic_feature_selection_results.md
```
